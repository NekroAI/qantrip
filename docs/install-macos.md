# 安装 Nekro Qantrip（macOS）

需要 macOS 14 或更新版本。

1. 下载对应芯片的安装包：Apple 芯片（M 系列）选 `Qantrip-<版本>-arm64.dmg`，Intel 芯片选 `Qantrip-<版本>-x86_64.dmg`。
2. 打开 DMG，把 **Qantrip** 拖进「应用程序」。
3. Qantrip 尚未经过 Apple 公证，首次打开会被系统拦截：到 **系统设置 → 隐私与安全性**，在页面底部点 **仍要打开**。
4. 跟随引导确认唤起快捷键（默认 ⌃Q），并授予「辅助功能」权限以便自动粘贴；不授权也能用，Prompt 会复制到剪贴板。

更新时下载新版本覆盖即可，权限、模板与设置都会保留。
