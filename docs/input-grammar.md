# 输入语法规范（草案 v0.1）

本文定义命令面板与 CLI 共用的输入语法：输入如何解析为"模板 + 参数值 + 附加文本"，以及匹配、补全和错误处理规则。

面板输入与图形化参数表单最终都归一为同一个结构，再交给同一个渲染器：

```
Invocation {
  template_id: string
  params: Map<param_name, value>
  extra_text: string?      // 附加要求，原样传给模板的 extra 变量
}
```

---

## 1. 预处理：全角规范化

中文输入法下用户常键入全角符号。**仅在参数区**（命令词之后、附加文本开始之前）做以下规范化，附加文本保持原样：

| 输入 | 视为 |
|---|---|
| `——`（U+2014 ×2）、`－－`、`—` 后接参数名 | `--` |
| `＝` | `=` |
| `，`、`、` | `,`（仅在参数值内） |
| `“…”`、`‘…’` | `"…"`、`'…'` |
| 全角空格 U+3000 | 空白 |

面板显示时应保留用户原始输入，只在解析层规范化。

## 2. 文法

```ebnf
input        = ws* , command , { ws+ , arg } , [ ws+ , free_part ] , ws* ;

command      = word ;                         (* 模板名或别名，见 §3 *)

arg          = long_opt | short_flags | positional ;

long_opt     = "--" , name , [ "=" , value ]  (* --strict  --scope=staged *)
             | "--no-" , name ;               (* --no-strict *)

short_flags  = "-" , letter , { letter } ;    (* -s  或组合 -sv，仅布尔短名 *)

positional   = word ;                         (* 仅当精确命中某位置参数的候选值，见 §4.3 *)

free_part    = "--" , ws+ , text              (* 显式开始附加文本 *)
             | text ;                         (* 隐式：第一个无法解析为 arg 的词起 *)

value        = item , { "," , item } ;        (* 多选用逗号 *)
item         = bare | quoted ;
bare         = ? 不含空白、逗号、引号的字符序列 ? ;
quoted       = '"' , ? 任意字符，支持 \" \\ \n ? , '"'
             | "'" , ? 任意字符，不转义 ? , "'" ;

name         = letter , { letter | digit | "-" | "_" } ;
word         = ? 不含空白的字符序列 ? ;
text         = ? 剩余全部原文，不再解析 ? ;
ws           = " " | "\t" | U+3000 ;
```

## 3. 命令词匹配

命令词为输入的第一个词（第一个空白之前）。

**匹配分层**（高层级总是排在低层级之前）：

| 层级 | 规则 | 示例（模板 `review` 别名 `r`） |
|---|---|---|
| L1 精确 | 名称或任一别名完全相等，不区分大小写 | `r`、`review`、`R` |
| L2 前缀 | 名称或别名以输入开头 | `rev` |
| L3 模糊 | 子序列 / 编辑距离容错 | `reveiw`、`rvw` |

**层内排序：** 收藏 > 使用频率（面板打开时取快照，输入过程中不变）> 名称字母序。

**Enter 与 Tab（D36）：**

- Enter = 按当前解析结果确认，即插入右侧预览显示的内容；L1 / L2 / L3 都一样（L3 时提示栏标明"↩ 插入 review"）。Enter 从不改写输入。
- 无法插入时（缺少必填参数、参数缺值、错误）Enter 不执行，底栏说明原因。
- Tab = 改写输入：接受高亮候选或灰字补全；没有候选时应用诊断的修正（如补上缺失的必填参数）。
- 指令模式同理：完整指令名或无歧义前缀（如 `/sy`）回车即执行，补全交给 Tab。

**别名冲突：** 两个模板声明相同别名时，模板库保存时报错，必须解决后才能保存；导入的 Pack 与本地冲突时，本地优先，Pack 的别名被标记为不可用并提示。

命令词一旦后接空白，即锁定为当前高亮模板（L3 情况同样锁定，但在提示栏显示"已匹配为 review"）。

## 4. 参数解析

命令词锁定后，从左到右逐词解析。

### 4.1 长选项

- 布尔：`--strict` = true；`--no-strict` = false；`--strict=false` 也接受。
- 非布尔参数**必须用 `=` 连接值**：`--scope=staged`。不支持 `--scope staged`，避免和位置参数、附加文本产生歧义。面板补全参数名时自动插入 `=`。
- 多选：`--focus=security,performance`，也可重复 `--focus=security --focus=performance`，结果合并去重并保持顺序。
- 参数名支持唯一前缀：`--sc=staged` 在无歧义时解析为 `--scope`，提示栏显示完整名。
- 枚举值支持唯一前缀：`--scope=st` → `staged`；有歧义时报错并列出候选。
- 多行文本参数可用引号加 `\n` 输入，但推荐用表单（Tab 进入）。

### 4.2 短选项

- 仅布尔参数可声明单字母短名：`-s` 等价于 `--strict`。
- 可组合：`-sv` = `-s -v`。

### 4.3 位置参数

- 模板可将**至多一个枚举或多选参数**声明为位置参数（`positional: true`）。
- 一个词只有在**精确等于**该参数的某个候选值或候选值别名时（不区分大小写，不做前缀匹配）才被解析为位置参数。
- 多选位置参数可以连续出现：`r security perf …`。
- 位置参数与对应的长选项同时出现时，以长选项为准并给出警告。

### 4.4 附加文本

附加文本从以下位置开始，**其后全部原文保留，不再解析**（包括其中的 `--`、逗号、引号）：

1. 显式：遇到单独的 `--` 词。
2. 隐式：遇到第一个既不是选项（不以 `-` 开头）、也不能解析为位置参数的词。

以 `-` 开头但无法识别的词**不会**被当作附加文本，而是报"未知参数"错误（见 §5）。如需以 `-` 开头的附加文本，使用显式 `--`。

**示例（模板 `review`，位置参数 `focus` ∈ {security, performance, …}）：**

| 输入 | 结果 |
|---|---|
| `r` | 全部默认值 |
| `r --scope=staged --strict --focus=security` | scope=staged, strict=true, focus=[security] |
| `r security 重点检查认证和权限模块` | focus=[security]，附加：`重点检查认证和权限模块` |
| `r security performance` | focus=[security, performance] |
| `r 安全相关的改动` | 附加：`安全相关的改动`（未命中候选值） |
| `r -- security 是重点` | 附加：`security 是重点`（显式开始，不解析） |
| `r ——strict` | strict=true（全角规范化） |
| `r --focus=security，performance` | focus=[security, performance] |
| `r --scop=x` | 错误：`--scope` 无候选值 `x`，列出候选 |
| `r --foo` | 错误：未知参数 `--foo`，建议最接近的参数名 |

## 5. 校验与错误处理

解析后、渲染前，依次校验：

1. 未知参数 / 未知候选值。
2. 类型（数值范围、格式）。
3. 必填参数是否齐全。
4. schema 中的依赖（`requires`）与互斥（`conflicts`）规则。

**行为：**

- 错误在输入时实时显示在提示栏，并标出对应的词。
- 存在错误时 Enter **不插入**：
  - 只缺必填参数 → Enter 打开参数表单，焦点落在第一个缺失项。
  - 其他错误 → Enter 无效，提示栏显示修正建议；Tab 可接受建议。
- 警告（如位置参数被长选项覆盖）不阻止插入。

## 6. 规范化表示

每次成功调用都可以序列化为规范形式，用于使用历史、"复制为命令"和测试快照：

```
<模板主名> [--参数=值 ...（按 schema 声明顺序，省略默认值）] [-- 附加文本]
```

例：`r security 重点检查认证` → `review --focus=security -- 重点检查认证`

同一个 `Invocation` 的规范形式唯一；解析规范形式必须得到相同的 `Invocation`（往返测试）。

## 7. 指令模式（D31）

输入以 `/`（或全角 `／`）开头时进入指令模式，用于管理用户模板。模板名不能以 `/` 开头，两者不会冲突。指令同样提供高亮、候选、灰字补全、诊断与预览；回车动作为"执行"。

| 指令 | 作用 |
|---|---|
| `/new 名称 [正文]` | 新建用户模板；不写正文时使用剪贴板文字（每次唤起只在输入 `/new ` 时读取一次） |
| `/edit 名称` | 在模板库中打开（内置模板等同于自定义） |
| `/dup 名称 新名称` | 复制模板（不复制别名），随后打开模板库 |
| `/alias 名称 别名` | 给用户模板添加别名；内置模板需先 `/dup` |
| `/rm 名称` | 删除模板（第二次回车才执行）：用户模板移到废纸篓；内置模板写入删除标记，可以恢复（D34） |
| `/restore 名称` | 恢复内置模板：撤销删除，或丢弃修改恢复内置版本 |
| `/sync` | 立即同步；未加入保险库时打开设置 › 同步 |
| `/settings` | 打开设置 |
| `/library [名称]` | 打开模板库；带名称时等同 `/edit` |
| `/lang auto\|zh\|en` | 切换内置模板语言（auto 跟随界面语言） |

`/new` 正文中的占位符（`core/src/placeholder.rs`）：

- `{名}` → 文本参数，使用时 `--名=文字`，文字填到这里。
- `{名:a|b|c}` → 单选参数，取值原样填入；第一个为默认值。
- `{名:取值=文字|取值=文字|=文字}` → 单选参数，命令里是 `--名=取值` 时输出对应的文字；`=文字` 是不写这个参数时输出的文字（有它时没有默认值）。取值只能用英文字母、数字、`-`、`_`、`.`（会出现在命令里）；没有 `=` 的项取值与文字相同，可以混用。
- `{名?文字|文字}` → 开关参数，加上 `--名` 时输出 `?` 后的文字，否则输出 `|` 后的文字（可省略）。
- 第一个单选参数同时是位置参数（每个模板至多一个位置参数，见 §4），可以写 `push test` 代替 `push --env=test`。
- 同名占位符可以出现多次：种类相同，单选的取值相同（各处输出的文字可以不同）。名称规则与参数名相同（英文字母开头）。
- 不符合以上写法的花括号原样保留（如 `{ "a": 1 }`）；包含 `{{`、`{%`、`{#` 的片段会被转义，不会被当作模板语法。写法有误（如取值含中文）时报错并说明原因。
- 描述取正文第一行（占位符显示为 `{名}`），末尾自动附加 `_extra`，附加要求照常可用。

输入过程中的提示（每个字符都更新）：

- 写名称时检查是否合法、是否已存在；正文阶段左侧列出三种写法（Tab 在末尾插入完整示例）。
- 光标在还没写完的 `{…` 中时，提示下一步可以写什么（`}`、`:`、`?`、`取值=文字`、`|`），并指出写错的地方；此时回车不创建。
- 右侧是效果预览：不带参数、每个选项、每个开关各渲染一次，显示创建后每种用法会生成的文字。
